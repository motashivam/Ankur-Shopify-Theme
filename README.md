# Ankur Family Shop - Shopify Theme

A native Shopify Online Store 2.0 theme converted from the original React storefront.

## Included

- Editable homepage sections for the hero, categories, featured products, shopping needs, brand promise, price links, and newsletter
- Native Shopify products, collections, variants, customer accounts, search, newsletter, cart, and checkout
- AJAX quick add and cart drawer
- Product, collection, cart, search, page, collection-list, and 404 templates
- Responsive desktop and mobile layouts
- Theme-wide logo, colors, social links, and content settings

## Preview

Authenticate Shopify CLI and run:

```powershell
shopify theme dev --store your-store.myshopify.com
```

## Validate

```powershell
shopify theme check --path .
```

## Package for upload

```powershell
shopify theme package --path .
```

Upload the resulting ZIP from **Shopify admin > Online Store > Themes > Add theme > Upload zip file**.

After installing, open the Theme Editor and assign the main navigation, footer menus, homepage collections, and category links.
